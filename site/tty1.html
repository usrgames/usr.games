tty1 is the launcher: one command that installs the games, keeps them current, and starts them.

Get it

$ curl -fsSL https://usr.games/install.sh | sh

$ go install usr.games/tty1@latest

Use it

tty1 ls
list the games
tty1 install rustwake
bring a game home
tty1 update
bring everything up to date
tty1 run rustwake
start a game
tty1 man rustwake
read a game's manual page
tty1 doctor
check your terminal, and say what a better one would give you
